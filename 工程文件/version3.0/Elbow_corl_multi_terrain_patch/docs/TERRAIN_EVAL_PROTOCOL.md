# Terrain Evaluation Protocol

## Flat metrics

- Success rate
- Fall rate
- Traveled distance
- Command tracking error
- Energy proxy
- Foot slip rate

## Beam metrics

- Beam crossing success
- Fall rate
- Foot outside support rate
- Mean centerline error
- Minimum edge margin
- Yaw alignment error

## Stepping-stone metrics

- Sequence success
- Foot in gap count
- Mean distance to nearest stone center
- Missed foothold count
- Fall rate
- Traveled distance

## Suggested benchmark stages

1. Flat easy
2. Flat rough
3. Beam width 0.50m
4. Beam width 0.35m
5. Beam width 0.25m
6. Beam width 0.18m
7. Stones radius 0.22m, spacing 0.30-0.35m
8. Stones radius 0.16-0.18m, spacing 0.40-0.48m
9. Stones radius 0.10-0.14m, spacing 0.50-0.60m
10. Mixed terrain
