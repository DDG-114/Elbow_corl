# Terrain Evaluation Protocol

## Flat Metrics

- Success rate
- Fall rate
- Traveled distance
- Command tracking error
- Energy proxy
- Foot slip rate

## Beam Metrics

- Beam crossing success
- Fall rate
- Foot outside support rate
- Mean centerline error
- Minimum edge margin
- Yaw alignment error

## Stepping-Stone Metrics

- Sequence success
- Foot in gap count
- Mean distance to nearest stone center
- Missed foothold count
- Fall rate
- Traveled distance

## Suggested Benchmark Stages

1. Flat easy
2. Flat rough
3. Beam width 0.50 m
4. Beam width 0.35 m
5. Beam width 0.25 m
6. Beam width 0.18 m
7. Stones radius 0.22 m, spacing 0.30-0.35 m
8. Stones radius 0.16-0.18 m, spacing 0.40-0.48 m
9. Stones radius 0.10-0.14 m, spacing 0.50-0.60 m
10. Mixed terrain
